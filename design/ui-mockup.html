What this sketch decides

      
    
        
  • Default view is three things: caption, lyrics, Generate. Model and format hide behind one disclosure row that still shows its state in the summary, so nothing is secretly wrong.
    • 
        
  • Fields are a writing surface, not boxes — hairline rules, no input chrome, counters in the label row.
    • 
        
  • The wait is honest. No spinner: elapsed time, a plain sentence saying the API reports no progress, and Cancel.
    • 
        
  • Song title leads the page, set once and carried into the folder name, the history entry, the file tags and run.json. Takes are numbered under it.
    • 
        
  • History is a rail, not a screen, collapsible from the titlebar. Each take offers Play, Clone and Reveal.
    • 
      

    

    

      
Recipe & receipt

      
    
        
  • One folder per song, takes inside.
          
    ~/MiniMaxMusic/
  six-flights-up/
    song.md        ← recipe
    take-01/
      track.wav
      run.json     ← receipt
    take-04/
      …
    • 
        
  • song.md is the inputs — YAML front matter for settings, ## Caption and ## Lyrics for the writing. Hand-editable, rewritten on every generate.
    • 
        
  • run.json is the record — trace_id, extra_info, call duration, exact payload sent. Never edited, one per take.
    • 
        
  • Splitting them matters: editing a recipe to try take 12 must not rewrite the provenance of take 11.
    • 
        
  • Three ways back in: drop a song.md on the window, the preset combo's Open a song.md recipe…, or double-click the file once the app owns the extension.
    • 
        
  • mp3 carries a copy in an ID3 comment frame, so a track that leaves the library still holds its recipe. wav and pcm are skipped — tagging them is fragile and DAWs strip it.
    • 
      

    

    

      
Auto-write lyrics

      
    
        
  • No second API key. lyrics_optimizer is a boolean on the same
          /v1/music_generation call. Set it true with lyrics empty and the music model
          writes the words itself.
    • 
        
  • But the words never come back. The response carries data.audio and
          extra_info — no lyrics text. So the take is unreproducible: generate twice from the same
          caption and you get two different songs with no record of either.
    • 
        
  • The fix is already in your spec. Send the finished track to
          music_cover_preprocess — the free step from the Cover flow — and it returns
          formatted_lyrics, ASR'd with section tags. Write those into song.md and the hole closes at
          no cost.
    • 
        
  • Turn the switch on to see how this is surfaced in the form.
    • 
      

    

    

      
Lyric tools

      
    
        
  • The whole thing works with no key and no network. Syllables and rhyme come from a
          bundled pronunciation dictionary — the full CMU set is ~134,000 words and a few hundred KB
          in the binary.
    • 
        
  • Rhyme is compared as sound, not spelling. Each word's rime — last stressed vowel to
          the end — is matched phonetically, so love/glove pair and love/move don't,
          and eight/gate/weight/late all pair across four spellings. Letter-matching gets
          every one of those wrong.
    • 
        
  • The gutter shows each line's count and its rhyme letter, assigned per section;
          · means no partner. A count shown as ~9 fell back to the spelling
          heuristic because the word isn't in the dictionary — rare with the full set, common in
          this sketch, which carries about a hundred words.
    • 
        
  • Check runs offline too. Three measured findings need no model at all — parallel
          lines drifting three or more syllables, an unrhymed line in a rhyming section, lines too
          long for one breath. All arithmetic over the two primitives above.
    • 
        
  • The assistant is off by default and is the only thing that leaves the machine.
          Tick it on in Settings and add an OpenRouter key; leave it alone and no text model is ever
          contacted. Enhance shows an off tag until you enable it.
    • 
        
  • A model adds the craft layer only — imagery, cliché, prosody. Those notes are
          labelled with the model that wrote them; measured notes aren't.
    • 
        
  • No line numbers. Findings anchor the way a musician would say it —
          Chorus 2 · line 2 — with the line quoted beneath. Hover lights the row in the
          gutter; click the quote to jump. A repeated chorus is one note, not one per repetition,
          and a rewrite applies to every copy.
    • 
        
  • Enhance never edits in place: a diff, one row per rewrite, everything tickable,
          and an Undo afterwards.
    • 
        
  • Honest caveats: the dictionary is English-only, and the
          mockup's rewrites are generated locally rather than by a model.
    • 
      

    

    

      
Try these

      
    
        
  • Open the preset combo and type "inst" or "bpm" — filter as you type, arrows and Enter to pick.
    • 
        
  • Rename the song — the folder path under the title updates live.
    • 
        
  • Type past 2,000 characters in Caption — counter turns red, Generate disables.
    • 
        
  • Toggle Instrumental — lyrics recede and Auto-write locks out.
    • 
        
  • Hit Generate, then Clone the result and generate again — same title, next take number.
    • 
        
  • Watch the syllable gutter as you edit a lyric line; toggle it off with the button above the field.
    • 
        
  • Check lyrics on the shipped verse — four notes, one with a rewrite. Then Enhance… and apply it.
    • 
        
  • Click song.md… beside Generate to read the recipe the current form would write.
    • 
        
  • Save a copy of it, edit the lyrics in any editor, then drag the file back onto the window — the parser is real, not faked.
    • 
        
  • Rename the song to "third coffee!" — it collides with an existing take's slug, so the path becomes third-coffee-2.
    • 
        
  • Gear icon → Appearance for System / Light / Dark.

Settled in review

      
    
        
  • Cover stays a tab.
    • 
        
  • A/B compare dropped. The player bar is just transport and Reveal now.
    • 
        
  • Song Title added as the first field on both Compose and Cover.
    • 
        
  • Presets: flat, filterable combo — search box over the list, ComfyUI-style.
    • 
        
  • Theme follows the system by default, overridable in Settings.
    • 
        
  • Song folder holds take subfolders, with song.md at the root.
    • 
        
  • Missing reference audio never blocks a drop — the rest of the form restores and the reference is flagged, with Locate and Continue.
    • 
        
  • Colliding folder slugs get -2, no prompt.
    • 
        
  • Recipe copied into ID3 for mp3 only.
    • 
        
  • Auto-write needs no extra key, and recovers its lyrics through the free preprocess endpoint.
    • 
        
  • Lyric tools are offline and standalone — dictionary-backed syllables, phonetic
          rhyme, and the measured checks, with no key and no network.
    • 
        
  • The lyric assistant ships off, behind an explicit tick plus a key in Settings.
